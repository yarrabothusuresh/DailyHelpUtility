# DailyHelpUtility
Daily Help Utility

## Utilities
- [Home Loan EMI Calculator](home-loan-calculator/) - EMI, end date and rate-change impact (Fixed EMI / Fixed tenure)

## Deployment
Netlify publishes this repository as a static site using `netlify.toml`; no build command is needed. The homepage (`/`) redirects to `/home-loan-calculator/`, which contains the calculator's `index.html`.
